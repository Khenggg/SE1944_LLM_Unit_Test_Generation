# Statistical Hypotheses Draft (RBL-2 Definitive Edition)
**Date:** 2026-06-04 | **Target Confidence Level:** alpha = 0.05

## 1. Research Questions (PICO Formulated)
* **Core RQ:** For intermediate-complexity Java/Python functions (P), do automated test cases generated via zero-shot GPT-4o / DeepSeek-Coder (I) achieve a structural branch coverage >= 80% and a semantic mutation score >= 60% (O) while significantly outperforming or matching student-written unit tests (C)?

---

## 2. Formal Statistical Hypotheses Formulation

### RQ1: Structural Adequacy Assessment (Branch Coverage)
* **H0_1 (Null Hypothesis):** Unit tests generated by GPT-4o/DeepSeek-Coder for intermediate-complexity functions do **not** achieve a median branch coverage greater than or equal to the 80% threshold ($Median(Cov) < 0.784$).
* **H1_1 (Alternative Hypothesis):** Unit tests generated by GPT-4o/DeepSeek-Coder for intermediate-complexity functions **do** successfully achieve a median branch coverage greater than or equal to the 80% threshold ($Median(Cov) >= 0.784$).
* **Designated Statistical Test:** **One-sample Wilcoxon Signed-Rank Test**.  
    * *Justification:* Branch coverage yields continuous ratio data (0.00 to 1.00) constrained within a bounded interval, typically exhibiting a highly skewed, non-normal distribution.

### RQ2: Semantic Quality Assessment (Mutation Score)
* **H0_2 (Null Hypothesis):** Unit tests generated by GPT-4o/DeepSeek-Coder for intermediate-complexity functions do **not** achieve a median mutation score greater than or equal to the 60% threshold ($Median(Mut) < 0.562$).
* **H1_2 (Alternative Hypothesis):** Unit tests generated by GPT-4o/DeepSeek-Coder for intermediate-complexity functions **do** successfully achieve a median mutation score greater than or equal to the 60% threshold ($Median(Mut) >= 0.562$).
* **Designated Statistical Test:** **One-sample Wilcoxon Signed-Rank Test**.  
    * *Justification:* Mutation scores are continuous percentage data that violate normal distribution assumptions, mandating a non-parametric location test against the specified median value.

### RQ3: AI vs. Human Comparative Assessment (LLM vs. SE Students)
* **H0_3 (Null Hypothesis):** There is **no** statistically significant difference in test capability (measured via branch coverage and mutation scores) between automated LLM-generated tests and human student-written tests on the same target functions ($Dist_{LLM} = Dist_{Student}$).
* **H1_3 (Alternative Hypothesis):** There **is** a statistically significant difference in test capability between automated LLM-generated tests and human student-written tests on the same target functions ($Dist_{LLM} \neq Dist_{Student}$).
* **Designated Statistical Test:** **Paired Wilcoxon Signed-Rank Test** (Two-tailed).  
    * *Justification:* Since the LLM and the students are testing the **exact same set of functions**, the data points are paired by design. A non-parametric paired test is the most statistically powerful mechanism to detect variations in this setup.
