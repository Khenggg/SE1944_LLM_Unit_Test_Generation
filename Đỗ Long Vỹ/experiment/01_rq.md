# Research Question — LLM vs. Human Student Unit Testing
**Date:** 2026-06-04 | **Status:** Updated via RBL-2 Framework

## 1. Formal Research Question (RQ)
For intermediate-complexity Java and Python functions ($P$), do automated unit test cases generated via zero-shot prompting using GPT-4o and DeepSeek-Coder ($I$) successfully achieve a structural branch coverage $\ge 78.4\%$ and a semantic mutation score $\ge 56.2\%$ ($O$) while matching or outperforming the test artifacts written manually by Software Engineering students ($C$)?
