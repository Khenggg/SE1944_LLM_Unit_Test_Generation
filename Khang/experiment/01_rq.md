# Research Question - SE1944

## Topic

LLM for Unit Test Case Generation

## Research Question (Finalized Thresholds)

Đối với Java/Python functions ở cyclomatic complexity trung bình (P), GPT-4/GPT-4o tự động sinh unit test cases (I) so với test cases viết thủ công bởi sinh viên (C) có đạt branch coverage >= 56.5% và mutation score >= 57% (O) không?

## PICO

| Thành phần | Nội dung |
| --- | --- |
| P | Java/Python functions ở cyclomatic complexity trung bình (CC = 5-15) |
| I | GPT-4/GPT-4o tự động sinh unit test cases (temperature = 0) |
| C | Test cases viết thủ công bởi sinh viên |
| O | Branch coverage >= 56.5% và mutation score >= 57% |

> [!NOTE]
> **Lưu ý điều chỉnh ngưỡng (Threshold Adjustment):**
> Ngưỡng ban đầu (Branch coverage >= 80% và Mutation score >= 60%) đã được hiệu chuẩn và điều chỉnh giảm xuống dựa trên các giá trị floor value thực tế từ Evidence Table trong RBL-2 (chi tiết tại `design-rationale.md`):
> - Ngưỡng Branch Coverage điều chỉnh thành **56.5%** (dựa trên floor value từ paper GS030).
> - Ngưỡng Mutation Score điều chỉnh thành **57%** (dựa trên floor value từ paper GS001).
