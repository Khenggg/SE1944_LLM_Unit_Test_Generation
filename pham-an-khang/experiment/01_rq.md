# Research Question

**For Java/Python functions at medium cyclomatic complexity (P), could GPT-4 automatic generation of unit test cases (I) compared to manually written test cases (C) achieve >=80% branch coverage and >=60% mutation score (O)?**

---

## PICO Board

| Element | Description |
|---|---|
| **P – Population** | Java/Python functions at medium cyclomatic complexity (typically CC = 5–15) |
| **I – Intervention** | GPT-4 automatic generation of unit test cases |
| **C – Comparison** | Manually written test cases (developer-written / student-written) |
| **O – Outcome** | ≥80% branch coverage **and** ≥60% mutation score |

### Detailed Breakdown

#### Population (P)
- **Language**: Java and/or Python source code
- **Granularity**: Function-level or method-level units
- **Complexity**: Medium cyclomatic complexity (CC ≈ 5–15), meaning code with a moderate number of branches, loops, and decision points — not trivially linear, but not excessively complex

#### Intervention (I)
- **Tool**: GPT-4 (or GPT-4o, GPT-4-Turbo variants)
- **Task**: Automatic generation of unit test cases from the source code under test
- **Method**: Zero-shot, few-shot, chain-of-thought, or structured prompting strategies
- **Output**: Compilable and executable unit test suites (e.g., JUnit for Java, pytest for Python)

#### Comparison (C)
- **Baseline**: Manually written test cases authored by human developers or students
- **Context**: Tests written as part of standard development or classroom exercises, representing the typical quality of hand-crafted test suites
- **Note**: Some studies may also compare against automated baselines (EvoSuite, Randoop, CodaMosa) — these serve as secondary comparisons

#### Outcome (O)
- **Branch Coverage ≥ 80%**: The proportion of code branches exercised by the generated test suite, measured via tools such as JaCoCo (Java) or coverage.py (Python)
- **Mutation Score ≥ 60%**: The proportion of code mutants killed by the test suite, measured via mutation testing tools such as PIT / PITest (Java) or MutPy / mutmut (Python)
- **Success criterion**: GPT-4-generated tests must achieve **both** thresholds simultaneously to answer the RQ affirmatively
