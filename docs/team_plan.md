## Assignment Rule

The Phase 1 source assignment is temporary and only ensures all five members contribute to initial paper collection. For RBL-1, all main tasks remain literature-review tasks.

Dataset creation, prompt execution, manual tests, JaCoCo, PIT, result tables, and charts are later experiment-phase work, not RBL-1 deliverables.
