# Bảng Minh chứng Hệ thống (Evidence Table) — Huỳnh Cao Phước

Bảng minh chứng dưới đây tổng hợp kết quả sàng lọc toàn văn ($N = 7$ bài báo) từ nguồn cơ sở dữ liệu học thuật **OpenAlex**. Tất cả các nghiên cứu được chọn đều thỏa mãn đầy đủ các tiêu chí lựa chọn khoa học và cung cấp dữ liệu định lượng trực tiếp về độ bao phủ mã nguồn và khả năng phát hiện lỗi của các unit test sinh bởi mô hình ngôn ngữ lớn (LLM).
