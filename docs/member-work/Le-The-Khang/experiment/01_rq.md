# Research Question - SE1944

## Topic

LLM for Unit Test Case Generation

## Final Research Direction

This study evaluates GPT-4o-mini (gpt-4o-mini-2024-07-18) generated unit tests for Java functions from the HumanEval-Java benchmark and compares them with human-written benchmark tests on the same code units.

## Main RQ

For Java functions from the HumanEval-Java benchmark, do GPT-4o-mini (gpt-4o-mini-2024-07-18) generated unit tests achieve literature-backed branch coverage and mutation-score thresholds, and how do they compare with human-written benchmark tests on the same code units?

## Sub-RQs

### RQ1 - Branch Coverage Threshold

Do GPT-4o-mini (gpt-4o-mini-2024-07-18) generated unit tests achieve median branch coverage >= 30.22% on selected Java functions from the HumanEval-Java benchmark?

### RQ2 - Mutation Score Thresholds

Do GPT-4o-mini (gpt-4o-mini-2024-07-18) generated unit tests achieve median mutation score >= 4% (strict floor) and >= 40.21% (scientific reference target) on the same selected functions?

### RQ3 - Human Benchmark Test Comparison

On the same Java functions, how do GPT-4o-mini (gpt-4o-mini-2024-07-18) generated tests compare with human-written benchmark tests in terms of branch coverage and mutation score?

## PICO

| Component | Content |
| --- | --- |
| P - Population | Java functions from the HumanEval-Java benchmark (N = 50) |
| I - Intervention | GPT-4o-mini (gpt-4o-mini-2024-07-18) generated unit tests using a fixed prompt and temperature 0 |

| O - Outcomes | Branch coverage and mutation score |
