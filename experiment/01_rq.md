# Research Question - SE1944

## Topic

LLM for Unit Test Case Generation

## Final Research Direction

This study evaluates GPT-4o (gpt-4o-2024-05-13) generated unit tests for medium-complexity Java/Python code units and compares them with student-written coursework/assignment tests on the same code units.

## Main RQ

For Java/Python functions or classes with medium cyclomatic complexity, do GPT-4o (gpt-4o-2024-05-13) generated unit tests achieve literature-backed branch coverage and mutation-score thresholds, and how do they compare with student-written coursework tests on the same code units?

## Sub-RQs

### RQ1 - Branch Coverage Threshold

Do GPT-4o (gpt-4o-2024-05-13) generated unit tests achieve median branch coverage >= 30.22% on medium-complexity Java/Python functions/classes?

### RQ2 - Mutation Score Thresholds

Do GPT-4o (gpt-4o-2024-05-13) generated unit tests achieve median mutation score >= 4% (strict floor) and >= 40.21% (scientific reference target) on medium-complexity Java/Python functions/classes?

### RQ3 - Student-Written Test Comparison

On the same Java/Python functions/classes, how do GPT-4o (gpt-4o-2024-05-13) generated tests compare with student-written coursework tests in terms of branch coverage and mutation score?

## PICO

| Component | Content |
| --- | --- |
| P - Population | Java/Python functions/classes with medium cyclomatic complexity, operationalized as approximately CC = 5-15 where measurable |
