# Research Question - LLM-based Unit Test Generation

## RQ chính thức

Can unit tests generated by Large Language Models achieve comparable or better branch coverage and mutation score than human-written unit tests on the same programming tasks?

## PICO

- **P (Population):** Java/Python programming tasks or functions used for unit testing.
- **I (Intervention):** Unit tests generated by LLMs such as GPT, ChatGPT, or Codex.
- **C (Comparison):** Human-written unit tests or baseline automated test generation tools.
- **O (Outcome):** Branch coverage, code coverage, mutation score, pass rate, and test effectiveness.

## RQ1

Do LLM-generated unit tests achieve acceptable branch coverage on selected programming tasks?

## RQ2

Do LLM-generated unit tests achieve acceptable mutation score compared with human-written tests?

## RQ3

Are LLM-generated tests comparable to human-written tests in terms of test effectiveness?
