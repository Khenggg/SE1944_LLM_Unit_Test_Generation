# Inclusion / Exclusion Criteria - SE1944

## Inclusion Criteria

- **IC1 - Language:** Paper is written in English.
- **IC2 - Timeline:** Paper was published from 2019 to 2026.
- **IC3 - Context:** Paper is related to software engineering or software testing.
- **IC4 - Topic:** Paper discusses LLM/GPT/ChatGPT for unit test generation or test case generation.
- **IC5 - Evaluation:** Paper includes empirical evaluation using metrics such as coverage, mutation score, pass rate, compile rate, or equivalent test-quality measures.

## Exclusion Criteria

- **EC1:** Not related to software testing.
- **EC2:** Only about production-code generation, not test generation.
- **EC3:** Not related to LLM/GPT/ChatGPT.
- **EC4:** No empirical evaluation or measurable result.
- **EC5:** Abstract or necessary full text cannot be accessed.
- **EC6:** Duplicate paper already represented by another record.

## Screening Rule

If a paper is `UNSURE` during title/abstract screening, keep it for full-text screening.
