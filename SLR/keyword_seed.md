# Keyword Seed

RBL-1 uses keyword seeds derived from PICO before constructing Boolean search strings.

| PICO Element | Seed Keywords |
| --- | --- |
| Population | Java functions, Java classes, Python functions, Python classes, medium complexity, cyclomatic complexity, JUnit, pytest |
| Intervention | GPT-4, ChatGPT, large language model, LLM, unit test generation, test case generation |
| Comparison | manual tests, human-written tests, student-written tests, developer tests, EvoSuite, Randoop |
| Outcome | branch coverage, code coverage, mutation score, mutation testing, pass rate, test quality |

## Notes

- The refined scope includes both Java/JUnit and Python/pytest when studies report executable unit-test generation metrics.
- UI, API, acceptance-test, production-code generation, and text-similarity studies are out of scope unless they evaluate executable unit tests.
